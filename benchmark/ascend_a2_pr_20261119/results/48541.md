## Four-host model serving

In a four-host GLM-5.2 W4A8C8 serving replay, main and this PR each completed 72/72 requests, with the same 72 request hashes and exactly 1,728 output tokens. Mean TTFT was 24.67 → 8.71 s, p95 TTFT 35.41 → 12.98 s, and aggregate output throughput 11.13 → 21.24 tok/s. Mean client decode rate was 1.55 → 1.73 tok/s/request. P/D same-rank continuations went from 7/48 and 8/48 to 2/48 and 48/48. Generated token IDs matched for 19/72 requests. These are single-cohort observations with 24-token outputs and no retries.
