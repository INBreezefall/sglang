# Paged KV allocator Triton specialization

### Ascend 910B4 hardware validation · 2026-11-19

Compared `f7e7ccbd9f1b` with `2a88b4028692`. Two cold processes per arm ran on the same NPU in A–B–B–A order. Each started with an empty Triton cache, batch size one and 128-token pages. Eleven positive extend lengths crossed the 2,048-token boundary. Every emitted slot was checked against contiguous reference indices.

| Arm | Compiled NPU binaries per run | First calls across all lengths (s) | Warm median per call (ms) |
| --- | --- | --- | --- |
| main | 8 / 8 | 44.54 / 45.00 | 0.383 / 0.385 |
| PR | 3 / 3 | 29.43 / 28.83 | 0.379 / 0.391 |

First-call timings include compilation, allocator work and device synchronization. Warm timings use 12 additional calls per length and include synchronization. The cold reduction is 34.9%.

The changed-path CPU suite passed 1 test and 9 subtests. The staged SGLang Python sources matched the Git blobs for both revisions. [Protocol, reproducible scripts and raw samples](../README.md).
