# HiCache LPM reload cost

### Ascend 910B4 hardware validation · 2026-11-19

Compared `f7e7ccbd9f1b` with `374aec581e92`. The production LPM policy ordered matched 16-request queues with fixed prefix-match inputs. Eight requests required real pinned-host H2D copies and eight were already resident. The app replayed the same 17 measured queue permutations per process twice per arm on the same NPU. Both arms copied 242 MiB per wave.

| Metric | Default LPM | Weight 64 | Change |
| --- | --- | --- | --- |
| Mean request completion within wave (ms) | 11.725 | 5.022 | -57.2% |
| Entire wave (ms) | 15.330 | 16.928 | +10.4% |

These are medians of wave summaries, aggregated equally across the two runs. The queue fixture serializes request completion and uses fixed cache matches. Per-request completion and total elapsed time are separate outcomes.
