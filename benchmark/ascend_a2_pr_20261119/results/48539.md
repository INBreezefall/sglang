## Four-host model serving

In a four-host GLM-5.2 W4A8C8 serving replay, main and this PR each completed 72/72 requests, with the same 72 request hashes and exactly 1,728 output tokens. Mean TTFT was 24.67 → 8.68 s, p95 TTFT 35.41 → 14.31 s, and aggregate output throughput 11.13 → 18.36 tok/s. Mean client decode rate was 1.55 → 1.74 tok/s/request. P/D same-rank continuations went from 7/48 and 8/48 to 5/48 and 5/48. Generated token IDs matched for 17/72 requests. These are single-cohort observations with 24-token outputs and no retries. Prefill reported 0 host-hit tokens on main and 0 on this PR across the 72 formal requests. The controlled reload benchmark measures the cost of host-cache restores directly. A separate restart of main completed the same 72 requests at 9.36 s mean TTFT, 15.00 s p95 TTFT and 18.16 output tok/s. The two main runs produced identical generated token sequences for 13/72 requests. This PR matched the restored main for 10/72. These observations do not establish model quality equivalence. Relative to the restored control, this PR changed mean TTFT by -7.3%, p95 TTFT by -4.6% and output throughput by +1.1%. [Full protocol and per-request data](../serving/README.md).
