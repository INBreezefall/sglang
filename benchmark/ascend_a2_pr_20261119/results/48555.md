# Compact PD and HiCache indexers

### Ascend 910B4 hardware validation · 2026-11-19

Compared `f7e7ccbd9f1b` with `94d9156ae932`. The production NPU pool builder used the 78-layer GLM-5.2 configuration, 1,024 usable slots and 128-token pages. Each arm ran in two processes. Every process backed up two nonconsecutive host destinations, zeroed the device pages, restored all layers via the native kernel_ascend path, and compared every element including untouched pages. All nine round trips per process passed.
