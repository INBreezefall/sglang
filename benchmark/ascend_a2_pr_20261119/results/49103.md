# Bounded decode KV backfill

### Ascend 910B4 hardware validation · 2026-11-19

Compared `f7e7ccbd9f1b` with `5d1571b7884b`. Each trial ran the current decode preallocation queue against an actual 128-slot NPU allocator. Eighty slots were occupied when a 96-token head arrived. After eight empty polls, six four-token requests joined. Both arms then received the same release of 80 slots.

| Metric across 12 trials | FIFO | Backfill |
| --- | --- | --- |
| Small requests admitted before capacity release, each trial | 0 / 6 | 4 / 6 |
| Final reservations, each trial | 7 / 7 | 7 / 7 |
| Distinct allocated slots with validated device contents | 120 | 120 |

The fifth small request stopped at the fairness barrier in every enabled trial. Transport metadata used a test receiver. This comparison measures admission progress under controlled KV pressure.

The changed-path CPU suite passed 29 tests and 15 subtests. The staged SGLang Python sources matched the Git blobs for both revisions. [Protocol, reproducible scripts and raw samples](../README.md).

## Four-host model serving

In a four-host GLM-5.2 W4A8C8 serving replay, main and this PR each completed 72/72 requests, with the same 72 request hashes and exactly 1,728 output tokens. Mean TTFT was 24.67 → 10.09 s, p95 TTFT 35.41 → 16.33 s, and aggregate output throughput 11.13 → 18.01 tok/s. Mean client decode rate was 1.55 → 1.76 tok/s/request. P/D same-rank continuations went from 7/48 and 8/48 to 5/48 and 8/48. Generated token IDs matched for 16/72 requests. These are single-cohort observations with 24-token outputs and no retries. This serving cohort uses a uniform 24-token output cap and supplies no counter for admissions past a KV-blocked head. The 12 controlled allocator trials quantify backfill progress under pressure. A separate restart of main completed the same 72 requests at 9.36 s mean TTFT, 15.00 s p95 TTFT and 18.16 output tok/s. The two main runs produced identical generated token sequences for 13/72 requests. This PR matched the restored main for 14/72. These observations do not establish model quality equivalence.
