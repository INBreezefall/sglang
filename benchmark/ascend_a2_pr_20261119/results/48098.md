## Four-host model serving

In a four-host GLM-5.2 W4A8C8 serving replay, main and this PR each completed 72/72 requests, with the same 72 request hashes and exactly 1,728 output tokens. Mean TTFT was 24.67 → 10.99 s, p95 TTFT 35.41 → 13.57 s, and aggregate output throughput 11.13 → 19.91 tok/s. Mean client decode rate was 1.55 → 1.73 tok/s/request. P/D same-rank continuations went from 7/48 and 8/48 to 48/48 and 13/48. Generated token IDs matched for 15/72 requests. These are single-cohort observations with 24-token outputs and no retries. A separate restart of main completed the same 72 requests at 9.36 s mean TTFT, 15.00 s p95 TTFT and 18.16 output tok/s. The two main runs produced identical generated token sequences for 13/72 requests. This PR matched the restored main for 12/72. These observations do not establish model quality equivalence. Relative to the restored control, this PR changed mean TTFT by +17.4%, p95 TTFT by -9.5% and output throughput by +9.6%. The direction of the mean TTFT difference changes with the choice of control.
