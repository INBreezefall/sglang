### Ascend 910B4 hardware validation · 2026-11-19

Compared `f7e7ccbd9f1b` with `405ac4fc3d75`. The production prefill controller routed 24 sessions over three turns. Each of eight physical NPUs maintained an independent native paged allocator and radix cache (32,768 slots, 128-token pages). Each arm processed the same inputs with an idle snapshot at each wave boundary.
