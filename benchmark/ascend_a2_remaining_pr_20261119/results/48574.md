# #48574 · DeepEP Normal and LowLatency dtypes

Upstream main `1ed3e1d04b25ab007b4c80481b7b6e3a36836eb7` and the isolated candidate `9ba34b92034e82cb7336447e3e3fc9c500465f5d` ran on the same hardware. Both revisions ran twice in main, candidate, candidate, main order.

Eight physical ranks formed an HCCL group. All ranks used a 6,144-wide BF16 input, 256 experts, top-8 routing, 8 or 32 tokens per rank and a 1,536 MiB HCCL buffer. Each process group discarded two warmups per case and retained four repetitions per rank. The dispatch dtype came from SGLang. The native DeepEP buffer dispatched, dequantized when needed and combined each payload.
