# #48520 · Input-only prefix retention

Upstream main `1ed3e1d04b25ab007b4c80481b7b6e3a36836eb7` and the isolated candidate `778d5a2d93c93a7a138ae072efc8f1332749e4aa` ran on the same hardware. Both revisions ran twice in main, candidate, candidate, main order.

Each process released 12 EAGLE decode requests with four prompt lengths and three output lengths through release_kv_cache. A real NPU request table, single-layer MHA KV pool and 128-token page allocator exercised bigram matching, page rounding and deallocation. Matched input and output pages carried known values.
