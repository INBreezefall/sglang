# #48538 · MLA draft layout selection

Upstream main `1ed3e1d04b25ab007b4c80481b7b6e3a36836eb7` and the isolated candidate `05717bb9fda5c3e27647ffe5c8de71932dac8d8d` ran on the same hardware. Both revisions ran twice in main, candidate, candidate, main order.
