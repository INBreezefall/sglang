# #48576 · Per-request prefetch timing

Upstream main `1ed3e1d04b25ab007b4c80481b7b6e3a36836eb7` and the isolated candidate `a9270183dea9036c02fb73905cff2b839a1ec89e` ran on the same hardware. Both revisions ran twice in main, candidate, candidate, main order.

A real HiCache controller ran its query, read and synchronization threads with a one-rank Gloo MIN. A file fixture supplied 2 MiB per request. The probe consumed the acknowledgement, issued a real pinned H2D and verified the payload. Each process ran 16 requests. The benchmark called the production consume and forward trace emitters at its two caller boundaries.
