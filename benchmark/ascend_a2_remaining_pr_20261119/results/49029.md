# #49029 · Pageable KV backup fallback

Upstream main `1ed3e1d04b25ab007b4c80481b7b6e3a36836eb7` and the isolated candidate `7d66973c2b1e1103f612e129146628bb170d485a` ran on the same hardware. Both revisions ran twice in main, candidate, candidate, main order.

Real NPU MHA KV buffers held four layers of keys and values in 128-token chunks. On a healthy request the original device copy ran. On fault trials, a bounded torch dispatch hook raised OutOfMemoryError only for the first asynchronous host copy. Subsequent transfers executed on the physical NPU. Every completed backup was reassembled and compared against all eight original tensors.
