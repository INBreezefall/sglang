# #48096 · Paged radix eviction

Upstream main `1ed3e1d04b25ab007b4c80481b7b6e3a36836eb7` and the isolated candidate `4529862bc1ba51d239f68a29cfb8249abc4c0224` ran on the same hardware. Both revisions ran twice in main, candidate, candidate, main order.

Each process ran 12 page-allocation shortfalls across 2,048–3,584-token prefixes using a real Ascend paged allocator and the Python unified radix tree. The candidate set the tail chunk to 256 tokens. The probe compared every retained KV row against its original NPU tensor and checked the allocator and radix invariants.
