## Cross-host native transfer

Two physical hosts used separate NPU devices 1 and 2. Each arm ran two fresh endpoint pairs with eight 1 MiB destinations per pair. Ascend Direct 0.3.13.post1 verified 0/16 destination slices on main and 16/16 on the PR. The source recorded 0 and 16 native write calls respectively. To replay, run the probe on both hosts with CROSS_RANK set to 0 or 1, LOCAL_ADDR and PEER_ADDR set to their data-plane IPs, and the same RENDEZVOUS_PORT and CROSS_ROUND. Expose devices 0 through 7 and select the matching checkout and wheel on both hosts. Both arms used the plain endpoint format. Each arm supplied its own production allocation-registration plan.
