# #48632 · Mooncake worker binding failures

Upstream main `1ed3e1d04b25ab007b4c80481b7b6e3a36836eb7` and the isolated candidate `77ba9f6f799f26e4ab0a43093d2a9dbd60f2ab4b` ran on the same hardware. Both revisions ran twice in main, candidate, candidate, main order.

The native NPU transfer-loop thread and its ThreadPoolExecutor initialized with either a valid local device or an out-of-range local device. Both sender poll entry points were then called. A real healthy NPU reduction checked the worker context. Network initialization and room state were controlled fixtures.
