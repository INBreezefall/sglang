# #49077 · Ascend Direct endpoint naming

Upstream main `1ed3e1d04b25ab007b4c80481b7b6e3a36836eb7` and the isolated candidate `bb9c53a98e828ec38a3b4493b10c046858314837` ran on the same hardware. Both revisions ran twice in main, candidate, candidate, main order.

Two processes on distinct NPUs on one host used the same 0.3.13.post1 Ascend Direct wheel and the real SGLang Mooncake wrapper. Each arm bound the target CANN device in the launch-deadline thread before initialization and registered a full allocation. The main endpoint used the device suffix and the candidate selected plain naming. Each process checked remote lookup, a probe and eight 1 MiB writes.
