# #48575 · Pinned allocator prewarming

Upstream main `1ed3e1d04b25ab007b4c80481b7b6e3a36836eb7` and the isolated candidate `d225360ab183cb679885e3433d0a631e578a8ab0` ran on the same hardware. Both revisions ran twice in main, candidate, candidate, main order.

Each new process used the same 64 MiB pinned segment reserve. The candidate ran the worker startup hook once. Nine real pinned allocations and H2D copies followed. Timings below isolate first-use latency and report the separate cost of moving work into startup.
