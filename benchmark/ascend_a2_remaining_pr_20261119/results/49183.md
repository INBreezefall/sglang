# #49183 · Independent draft host budget

Upstream main `1ed3e1d04b25ab007b4c80481b7b6e3a36836eb7` and the isolated candidate `1b789051388cdf4bdd352c0b013840d93da834fe` ran on the same hardware. Both revisions ran twice in main, candidate, candidate, main order.

The draft assembler built a real single-layer MHA pool and pinned host storage at three target logical sizes. The candidate supplied 0.004 decimal GB per rank. The independent pool reserves a padding page, which is included in the measured allocation. Each allocation was filled and copied to the NPU and back. Whole-buffer digests naturally differ when pool lengths differ. Each returned payload matched its own original.
